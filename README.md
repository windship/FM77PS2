# Key Mapping
FM77AV <-> PS/2<br>
-------------------------<br>
Break   / Scroll Lock<br>
Home    / Home<br>
EL      / End<br>
DUP     / PageUp<br>
CLS     / PageDown<br>
Graph   / Left Alt<br>
Kana    / Right Alt<br>
